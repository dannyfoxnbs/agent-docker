# Key Domain Terms

## Branding

- `Nimbus`: platform or repo name.
- `Chorus`: the main app/product.
- `NBS Source`: product listing directory.
- `Cirrus`: internal technical name for the Source API/integration.
- `Lattira`: alternate brand to NBS.

## Core Terms

- `project`: default top-level container.
- `specification` (`spec`): default document term.
- `content set`: configured content library with its own terms and rules.
- `taxon`: a classification item or node inside a content set.
- `conceptId`: shared identifier used to link related content across versions.

## Content Terms

- `section`: a structural grouping used in sectional content sets.
- `sectional content set`: a content set where sections are first-class structure.
- `non-sectional content set`: a content set where content is typically added clause by clause rather than section by section.
- `article`: term used in sectional content sets for clause-like content within a section.
- `clause`: the base content unit.
- `clause instance`: a clause as it appears inside a specification, master, or bundle.
- `clause item`: a row within a clause.

## Context-Specific Terms

- `master`: document term used in master mode.
- `bundle`: document term used in content-production mode.

## Usage Rules

- Use `spec` in code and short plans; use `specification` in user-facing docs.
- Use `Chorus` for user-facing product wording.
